# Skins

A skin is a complete stylesheet for the public site, saved so a look can be kept, compared or restored.

| Skin | File | Status |
| --- | --- | --- |
| Broadsheet | `broadsheet.css` | The original newspaper-style design, saved Nov 10 2026. Cormorant Garamond and Inter, near-black and terracotta. |
| Collected workshop | coming | The new design from the Morenita Technology design brief: stone, ink, wine and brass; grotesk headlines and serif essays. |

The live `index.html` still carries its own styles. When the new skin is ready, the page will load one skin file instead.
